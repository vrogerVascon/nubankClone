# NubankClone

Clone of the Nubank app interface developed with Kotlin and XML in Android Studio.

This project recreates the modern visual experience of the banking app using native Android components, smooth layouts, and organized UI structure.

---

# ✨ Features

- Nubank-style header
- Account balance section
- Credit card section
- Horizontal RecyclerView
- Custom icons
- Responsive layout
- NestedScrollView support
- Modern purple interface
- Reusable components
- Clean project structure

---

# 📱 Interface

The app contains an interface inspired by the official Nubank application including:

- User profile
- Visibility button
- Help section
- Security/protection area
- Account balance
- Credit card information
- Horizontal quick actions list

---

# 🛠 Technologies Used

- Kotlin
- XML
- Android SDK
- RecyclerView
- ConstraintLayout
- NestedScrollView
- CardView
- ViewBinding
